# English UI

Strings already pass through Paraglide, with `sl` as the only locale (NFR-7).
Adding English is a translation file and a locale switcher, not a refactor —
which is exactly why the i18n layer went in on day one.

Worth doing when a group that does not speak Slovenian actually asks. Translating
in parallel with development is work nobody reads.
